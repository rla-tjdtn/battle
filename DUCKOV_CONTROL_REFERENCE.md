# Duckov Control Reference (V5)

Implemented in code. Play Mode human feel is unverified.

| Key | Action |
|---|---|
| WASD | Camera-relative move |
| Mouse | Aim (camera yaw stays fixed) |
| LMB | Fire |
| RMB | ADS (same quarter-view, tighter spread) |
| Shift | Run |
| Space | Dodge (~3m / 0.32s / 1s cooldown) — not jump, not vault |
| Left Ctrl | Crouch |
| Z | Prone |
| F | Interact: pickup, door, vehicle, plane exit |
| C | Holster / draw weapon — not crouch |
| V / 3 / 4 | Melee / fists |
| 1 / 2 | Primary guns |
| 5 | Heal |
| R | Reload |
| G | Grenade |
| Tab | Backpack |
| M | Map (if minimap present) |
| Esc | Menu |

BR extras (plane, zone, vehicles) do not replace these keys on the ground.
