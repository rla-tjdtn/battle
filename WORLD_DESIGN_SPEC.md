# World Design Spec (V3 Village Slice)

## Scale lock (1 unit = 1 m)

| Element | Size |
|---|---|
| Character | 1.55–1.8 m |
| Door | 1.0–1.3 m wide, ~2.1 m tall |
| Floor height | 2.7–3.2 m |
| Small house | 8–12 m footprint |
| Warehouse | 10–16 m footprint |
| Tree medium | 4–7 m |
| Tree small | 2.5–4 m |
| Road | 5–8 m wide |
| Fence | 1–1.5 m |

## Village slice

- Size: **220 × 220 m** playable pad (generator half-extent 110)
- Density: buildings + trees + props in every typical camera frame
- Terrain: mesh height 0–3.5 m gentle hills
- No copyrighted Duckov map copy — original layout

## Prop roles

| Tag | Role |
|---|---|
| HardCover | Blocks bullets + vision |
| SoftCover | Partial vision (grass) |
| CameraOccluder | Camera fade only |
| DecorativeOnly | Visual clutter |

## Lighting

- Warm directional day (golden)
- Soft shadows
- Indoor slightly darker via ambient + less direct
